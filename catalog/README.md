# Adventure Catalog Sources

The manifests under `assets/adventures/` are generated by `../build_catalog.py` from the source files in this directory:

- `languages.json`: JSON array of target language tags (e.g. `["pt", "zh"]`).
- `adventures.json`: Authored list of adventure entries (`id`, `source`, `title`, `description`, `bundle`, `previewImageUrl`, `tags`, `artistUrls`, `version`, and optional `variants`).
- `i18n/adventures.<tag>.json`: Optional per-language overrides keyed by adventure `id` (`title`, `description`, `previewImageUrl`).
- `i18n/tags.<tag>.json`: Optional per-language tag display dictionary (`{"<english tag>": "<translated tag>"}`).

## Commands

```bash
# Generate assets/adventures/manifest.json and manifest.<tag>.json
python3 build_catalog.py

# Validate and verify generated files match disk without writing
python3 build_catalog.py --check

# Run unit tests
python3 -m unittest catalog/test_build_catalog.py -v
```
